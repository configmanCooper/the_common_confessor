# Playtest Release Checklist

- Run `npm test`.
- Run `npm run test:browser`.
- Start with `npm run play`.
- Confirm Gemma reports ready or deterministic parish fallback is shown.
- Start with exactly 200 villagers on Monday.
- Complete four appointments and confirm Tuesday begins.
- Reach Sunday and deliver a sermon under 100 words.
- Export a save, import it from the start screen, and continue.
- Confirm the parish register and chronicle open correctly.

The one-year balance command is intentionally reserved for final balance passes.
